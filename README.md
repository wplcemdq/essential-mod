# Essential Mod

> **Minecraft Client Mod** | Version v1.3.4 | Platform: Java Edition 1.8.9 – 1.21.4

## About

Essential is a quality-of-life mod for Minecraft that adds multiplayer features to singleplayer, cosmetics, and social tools. Fully compatible with Forge and Fabric mod loaders.

## Features

- Multiplayer in Singleplayer
- In-game cosmetics
- Screenshot sharing
- Friend list
- Wardrobe system
- Skin editor
- Server invites
- Zoom feature
- Performance improvements
- Mod compatibility

## System Requirements

- Requires Minecraft Forge or Fabric
- Cosmetics are account-bound
- Social features require internet connection

## Installation

1. Download the latest version of **Essential Mod** from the link below
2. Run the installer and follow the on-screen instructions
3. Launch Minecraft and enjoy
