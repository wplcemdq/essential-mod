## 📖 About

Essential is a quality-of-life mod for Minecraft that adds multiplayer features to singleplayer, cosmetics, and social tools. Fully compatible with Forge and Fabric mod loaders.

## ⚠️ Problems Without Essential Mod

| Problem | Status |
|---------|--------|
| Requires Minecraft Forge or Fabric | ✅ Fixed |
| Cosmetics are account-bound | ✅ Fixed |
| Social features require internet connection | ✅ Fixed |

## ✅ Solution

**Essential Mod v1.3.4** addresses all of these limitations with a feature-complete solution for **Java Edition 1.8.9 – 1.21.4**.

## 🎯 Features

- Multiplayer in Singleplayer
- In-game cosmetics
- Screenshot sharing
- Friend list
- Wardrobe system
- Skin editor
- Server invites
- Zoom feature
- Performance improvements
- Mod compatibility
